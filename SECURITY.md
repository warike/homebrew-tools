# Security Policy

## Cask Verification

All casks in this tap include:
- **SHA256 checksums**: Every download is verified against a cryptographic hash
- **HTTPS only**: All download URLs use secure connections
- **Official sources**: Downloads point to official GitHub releases only

## Reporting a Vulnerability

If you discover a security issue with any cask in this tap:

1. **Do not** open a public issue
2. Email the maintainer directly or use GitHub's private vulnerability reporting
3. Include the affected cask and details of the vulnerability
4. Allow reasonable time for a fix before public disclosure

## Best Practices

When installing from this tap:
- Always verify the cask source before installing
- Check that download URLs point to trusted sources
- Review the cask file if you have concerns
